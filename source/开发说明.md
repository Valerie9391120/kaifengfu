# 开发说明

写给以后接着改开封府的人（多半是我自己）。

## 先读这条

这个仓库是**公开的**。名帖、信、聊天、日记、照片、暗号、各种 key，一样都不许进仓库，测试里也只用编的假数据。私人内容只存在她手机上，加密后同步到 Supabase。

## 结构

| 位置 | 是什么 |
| --- | --- |
| 仓库根目录 | 打包好的网页，GitHub Pages 直接发布 |
| `source/src/main.jsx` | 入口；量出 iOS 主屏幕底下空一条时在 `<html>` 上记一笔，页面最底下淡进那条的颜色 |
| `source/src/Gate.jsx` | 门口：登录、设暗号、对暗号 |
| `source/src/App.jsx` | 开封府本体：聊天、侧栏、记忆库、日记本、表情包、MCP、API 面板 |
| `source/src/vault.js` | 暗号 → 钥匙（PBKDF2 60 万轮），AES-GCM 加密，钥匙名用 HMAC 打乱 |
| `source/src/engine.js` | 同步引擎：本地先存，加密后推上云端；拉取、墓碑、断网补传 |
| `source/src/localdb.js` | 手机本地存档（IndexedDB） |
| `source/src/cloud.js` | Supabase 登录、库房读写、调用 `claude` 函数 |
| `source/src/errors.js` | Anthropic 的报错翻成中文，说清去哪儿改 |
| `source/src/store.js` | App 读写存档的统一入口 |
| `source/src/config.js` | Supabase 网址和 publishable key（本来就公开） |
| `source/static/` | 开屏图、燕子、聊天背景、主屏幕图标、表情包缩略图 |
| `source/supabase/database.sql` | 库房建表和权限（在 Supabase 的 SQL Editor 里运行） |
| `source/supabase/claude_function.ts` | 传话的小后端（Supabase Edge Function，名字叫 `claude`） |
| `source/tests/` | 单元测试、假 Supabase、端到端测试 |

## 改前端

```
cd source
npm install
pip install playwright pillow                    # 测试用；浏览器用机器上装好的 Chrome
# 改 src/ 里的代码
npm run test:unit
npm run build:test
npm run mock &                                   # 假 Supabase，端口 8787
(cd dist-test && python3 -m http.server 8080 &)  # 测试网页，端口 8080
npm run test:e2e                                 # 真浏览器走一遍完整流程
python3 tests/fullscreen.py                      # 主屏幕底下空一条：输入框贴底、淡出、四种情况
npm run build                                    # 正式包，在 dist/
```

把 `dist/` 里的东西复制到仓库根目录，连同改过的 `source/` 一起提交推送。GitHub Pages 几分钟后更新，她把 app 从后台彻底划掉再打开就能看到。

## 改后端

`claude` 函数和数据库不在 GitHub 上运行，改了以后要她在 Supabase 网页上贴进去：

- 函数：Edge Functions → `claude` → 换成新代码 → Deploy
- 数据库：SQL Editor → 运行新的 SQL
- 密钥柜：Edge Functions → Secrets（`ANTHROPIC_API_KEY`、`ALLOWED_EMAIL`）

密钥柜里的值改了不用重新 Deploy，函数下一次被叫到就读新的。

Anthropic 的 key：在 Claude Console 的 Settings → API keys → Create key 新建。新版 Console 的 key 分“绑定一个工作区”和“能用好几个工作区”两种，后一种每次请求都得带 `anthropic-workspace-id` 头，否则报 “This API key is not scoped to a workspace”。我们的函数不带这个头，所以建 key 时一定要选一个工作区；过期时间选“永不过期”，不然到期那天开封府就哑了。

## 要她重新添加到主屏幕的改动

`index.html` 里 `apple-mobile-web-app-*` 开头的设置、主屏幕图标、App 名字：iOS 在添加到主屏幕时读，改了要删掉图标重新添加。删之前先确认账户面板里写着“都已同步”。

## 几个约定

- 名帖和对话用提示缓存：名帖一小时，最后一句话后面放五分钟的记号；【此刻】的时间附在最后，不打乱缓存。
- 对话窗口二十条一跳，跳之前前缀不变，缓存一直命中。
- 记忆库的文档管“你们是谁”，`App.jsx` 里的【回复格式】管“怎么回”，两者冲突时听回复格式的。
- 表情包仓库的 README 每次打开都会读，新图自动出现；烤进来的 49 张在 `static/memes.json`。

## iOS 主屏幕底下那一条

iOS 26 以后有几个版本有个毛病（WebKit Bug 301108）：主屏幕上的网页用了 `black-translucent` 铺到状态栏底下以后，整个网页会矮一个状态栏，最底下空出一条系统画的色块，颜色取网页底色（`input.css` 里 `html, body` 的 background，系统会缓存，重开两次才换）。网页画不到那里，补高没用，只会把输入框挤出屏幕；别人试过 `100lvh`、`-webkit-fill-available`、写死像素，在真机上都一样。

现在的处理（`main.jsx` 量出这种情况时，在 `<html>` 上记 `data-kfs-gap="bottom"`）：

- 底色设成两张背景图最底边的颜色 `#D6DCCD`。
- `--kfs-sab`（`input.css`）：平时等于 `env(safe-area-inset-bottom)`，空一条时是 0，因为网页本来就够不着底下横条，不用再让。
- 输入框整块贴到网页最底边（`App.jsx` 的 `DOCK_GLASS`），上半截是玻璃，最底下淡进 `#D6DCCD`，和那条接上，看着像一直铺到屏幕底。按钮的影子要小，大了会被网页底边切掉一截。
- 侧栏最底下那排（头像、新对话）也贴底，底下垫一段渐变（`.kfs-dock-fade`）。
- 开屏、门口、日记、历史、弹出面板这些页面，最底下加一段淡出（`.kfs-bottom-mist`）。对话页在最上面时 App 会在 `<html>` 上记 `data-kfs-chat`，淡出退掉，不然按钮会发白。

`tests/fullscreen.py` 量这几样：输入框贴底、按钮离底边 8、底边颜色和那条差不过 4、什么时候有淡出。

要是想把空条挪到顶上（顶上是实心状态栏、底下贯通，输入框能贴到真正的屏幕底），把 `index.html` 的状态栏样式改回 `default`，她要删掉图标重新添加。
