# 瓶花（图画院框景左下角那一瓶，每天换一束）

园子里那十二种花都在 Blender 里用程序建出来，固定一只瓶子，插十瓶，每天换一瓶。
瓶子：月白釉、亮面、没有镂空浮雕。颜色照园子里那几段花开的话
（`vendor/garden/garden-data.ts` 的 bloomText）；园子里没写颜色的三样我挑的：茶花深红、月季粉、木槿淡粉紫。
魏紫照书房那一页里那朵的颜色（紫红，瓣边浅紫透光）。

要装 bpy（`pip install bpy numpy`，Blender 5.2 的那一份能在没有屏幕的机器上跑），合成看样子那一步要 opencv-python、pillow。

| 文件 | 是什么 |
|---|---|
| `kit.py` | 共用：清场、渲染设置（Cycles、透明底、AgX）、光（照恩师那张框景：左前上方一盏大暖光）、相机、月白瓶、网格和材质小工具 |
| `flora.py` | 各种花共用的形状：叶片（椭圆/卵形/披针/带状，可带锯齿）、带状叶、圆瓣、漏斗花冠、杯状副冠、几种材质 |
| `peony.py` | 魏紫、玉楼春（`mats('weizi')`/`mats('yulouchun')`；玉楼春用 `RINGS_YLC`，花心一座“楼子”） |
| `plum.py` | 白梅（之字形的老枝、细直的新枝、五瓣白花、红褐色的萼、花苞） |
| `begonia.py` `orchid.py` `azalea.py` `camellia.py` `osmanthus.py` `rose.py` `narcissus.py` `chrysanthemum.py` `hibiscus.py` | 西府海棠、芷兰、映山红、茶花、金桂、月季、水仙、秋菊、木槿 |
| `bouquet.py` | 第 1 瓶（魏紫 · 白梅）：`python bouquet.py 出图.png 800 1370 96` |
| `arrange.py` | 第 2～10 瓶：`python arrange.py 编号 出图.png 800 1370 96` |
| `spec.py` | 单看一种花：`python spec.py 模块名 出图.png` |
| `one.py`、`sheet.py`、`onbg.py` | 单看一朵、拼小样、铺在墙色上看 |
| `compose.py` | 把恩师那张框景里画的瓶子抹掉，贴上一瓶看样子（只是看样子；页面上是一层一层叠的） |
| `mouthcheck.py` | 查瓶口穿模：`python mouthcheck.py 编号 [瓶口特写.png]`（见下面“瓶口”） |

十瓶都是同一个机位（瓶心在画面中心左边 0.55 单位，瓶底在 (278, 1325)，一单位 214 像素），
出好的 PNG 交给 `tools/make_tuhua_assets.py` 转成 `static/tuhua/vase1..10.webp`，顺带量每一瓶最高到哪儿（`tuhua.js` 的 `VASE_TOPS`、`VASE_RIGHTS`）。
十瓶的搭配：1 魏紫·白梅，2 玉楼春·西府海棠，3 茶花·水仙，4 秋菊·金桂，5 月季·芷兰，6 映山红·玉楼春，7 木槿·水仙，8 魏紫·玉楼春，9 白梅·茶花，10 秋菊·芷兰。

**瓶口**。原来每根枝梗都从瓶里一点（口沿往下 0.55）起头，照着花要去的地方直直出去；
瓶颈细，枝一歪就从瓶颈、口沿上戳出来，有几枝干脆从瓶肩上横穿出去。现在：

- `kit.vase()` 建好瓶子就沿一条经线量一圈纵剖面（细分、加厚以后的真样子：口沿顶 z=2.206，口沿里面内径 0.217，瓶颈最细处内径 0.149）。
  `kit.where(点)` 说一个点在瓶外、瓶里还是瓷里头，`kit.clearance(点)` 说离瓷面多远。
- `kit.neck(中线, 半径)`：从瓶里起头的那根，要是碰了瓷，就把瓶里那截重新走——从口沿里面出来（往哪边歪就从哪边出，歪得厉害的靠口沿；
  几根的出口错开），出瓶那一段一条顺的弧，接上原来露在外面的那截（接头往后一点不动，点数、长短都不变，沿枝按位置挂的东西还在原地方）；
  瓶里那截顺着瓶颈下去，快碰壁就往瓶轴那边拐（看不见）。接在哪儿：挑出瓶以后拐得最缓、又不和先插的几根穿在一起的；
  木本的枝（`woody=True`：梅的老枝、海棠、映山红、金桂）多留原来那几道折，宁可接得早些。
  实在从瓶口出不来的（贴着瓶身横出去的），整根往上提，提到能顺顺出来为止（十瓶里只第 2 瓶那枝低低横出去的海棠提了 0.36）。
- 沿枝挂的叶子、刺落在出瓶以前的就不挂了（插花本来就把瓶口以下的叶子摘掉），花、苞挪到出瓶以后（`Neck.ok`、`Neck.up`、`Neck.spread`）。
  不挂的那片照样建一遍、扔进 `kit.SINK`：随机数照旧往下走，别的叶子、花一点不变。
- 各花的 `stem`/`branch` 建中线以后先过一遍 `kit.neck`，再挂叶子、花；梅的老枝在 `bouquet.py`、`arrange.py` 的 `a9` 里过。
- `python mouthcheck.py 编号 [特写.png 宽 采样]`：搭一遍那一瓶、不出整图，列出每根从瓶里起头的枝梗离瓷面最近多少、从哪儿出的瓶、`neck` 改了哪几根，
  再把所有花叶枝的顶点过一遍（有没有落进瓷里头的）、瓶口上头两根有没有穿在一起；给了路径就再拍一张瓶口特写（机位不动，只是拉近）。
  `KIT_NO_NECK=1` 跑就是不改的原样（对比用）。十瓶现在都是“干净”。

**牡丹的叶**：第 1、2、6、8 瓶瓶口那几片三出复叶原来是照一个点单摆在瓶口那儿的，
叶柄的头悬空，离最近的花梗差 0.01～0.3。现在 `peony.stem` 记下这个园子里建好的梗，`peony.leaf` 的叶柄从离那个点最近的梗上（瓶口以上）长出来，
斜斜往上出，弯过去接到三片小叶那儿；小叶还在原地方，随机数照旧。园子里没有梗的（单看一片叶子）照原样。
